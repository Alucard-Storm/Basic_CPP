# Experiment 1: Hello World

**Section A — Basic Programming and Operators**

## Aim

Write a C++ program to display “Hello, World!” and demonstrate the basic structure of a program.

## Concepts Used

Program structure, `#include`, `main()`, `cout`

## Program

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

## Sample Run

**Output**

```text
Hello, World!

```

## Result

The program was executed successfully and the output was verified.
