# Experiment 12: Quotient Remainder

**Section A — Basic Programming and Operators**

## Aim

Write a program to calculate the quotient and remainder of two integers.

## Concepts Used

`/` and `%` on integers

## Program

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "Enter dividend and divisor: ";
    cin >> a >> b;
    cout << "Quotient = " << a / b << endl;
    cout << "Remainder = " << a % b << endl;
    return 0;
}
```

## Sample Run

**Input**

```text
47 5
```

**Output**

```text
Enter dividend and divisor: Quotient = 9
Remainder = 2

```

## Result

The program was executed successfully and the output was verified.
